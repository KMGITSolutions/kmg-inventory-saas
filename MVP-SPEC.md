 # Inventory SaaS MVP

## Goal

Help small businesses manage inventory and sales.

## MVP Features

### Authentication
- Log in.
- Log out.

### Products
- Add a product.
- Edit a product.
- Delete a product.

### Inventory
- Record stock in.
- Record stock out.

### Sales
- Add a sale.
- View sales history.

### Dashboard
- Display total products.
- Display total sales.
- Display low-stock products.
